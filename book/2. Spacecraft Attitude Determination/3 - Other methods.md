
# 3. Прочие методы определения ориентации

В этом разделе кратко рассматриваются более универсальные и точные методы определения ориентации, основанные на решении оптимизационных задач. Подробности реализации опущены - цель состоит в том, чтобы дать общее представление о подходах. Приведенный обзор не является исчерпывающим и охватывает лишь часть известных статических алгоритмов.

## 3.1. Общая постановка задачи

Рассмотрим случай, когда на борту космического аппарата установлено $N > 1$ датчиков, измеряющих ориентацию относительно направлений на различные ориентиры - например, Солнце, Землю, звезды, относительно линий магнитного поля и т.д. Пусть измерения в связной системе координат обозначаются как:

$$\overline{v}_i^{\text{B}},\ \ \ \ i=1, .., N,$$

а соответствующие опорные векторы в инерциальной системе координат как:

$$\overline{v}_i^{\text{I}},\ \ \ \ i=1, .., N.$$

Связь между векторами задается матрицей ориентации $\textbf{C}_{\text{I} \rightarrow \text{B}}$:

$$
\overline{v}_i^{\text{B}} = \textbf{C}_{\text{I} \rightarrow \text{B}}\ \overline{v}_i^{\text{I}},\ \ \ \ i=1, .., N.
$$

Задача сводится к нахождению такой матрицы поворота $\textbf{C}_{\text{I} \rightarrow \text{B}}$, которая минимизирует суммарную невязку между измеренными и расчетными векторами:

$$
J(\textbf{C}_{\text{I} \rightarrow \text{B}}) = \sum_{i=1}^{N} w_i \left|\left| \overline{v}_i^{\text{B}} - \textbf{C}_{\text{I} \rightarrow \text{B}}\ \overline{v}_i^{\text{I}} \right|\right|^2 \rightarrow min,
$$

где $w_i$ - весовые коэффициенты, отражающие степень доверия к измерениям конкретных датчиков (в простейшем случае $w_i = 1$ для всех $i$).

Эта формулировка известна как **задача Вахба** ([Wahba's Problem](https://en.wikipedia.org/wiki/Wahba%27s_problem)). Большинство методов статического определения ориентации основываются на ее решении.

## 3.2. Основные методы решения задачи Вахба

Ниже приведены три классических метода решения задачи Вахба. Каждый из них использует различную математическую технику для получения оптимальной оценки ориентации.

* [Davenpot's q-Method](https://ahrs.readthedocs.io/en/latest/filters/davenport.html)

  Классический подход, формулирующий задачу в терминах кватернионов. Сводит ее к поиску собственного вектора матрицы, построенной по измерениям. Позволяет получить точное решение, но требует вычисления собственных значений.

* [QUEST (QUaternion ESTimator)](https://ahrs.readthedocs.io/en/latest/filters/quest.html)

  Оптимизированная версия предыдущего метода. Предлагает итерационное решение для поиска максимального собственного значения, что делает метод более эффективным для реализации в реальном времени.

* [Optimal Linear Attitude Estimator (OLAE)](https://www.researchgate.net/profile/Landis-Markley/publication/242092051_Optimal_Linear_Attitude_Estimator/links/00463533d8a18a9904000000/Optimal-Linear-Attitude-Estimator.pdf)

  Линейный метод, приближенно решающий задачу Вахба с использованием векторных разностей.
